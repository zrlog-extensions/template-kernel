# Kernel 设计与维护说明

Kernel 是原创的极客博客主题，整个浏览过程围绕一个终端会话展开。首页呈现 `ls` 文稿目录，详情进入 `less` 单栏阅读；分类、标签和归档都是可进入的路径。命令只处理博客导航、服务端搜索与本地配色偏好，不执行系统 shell 或任意脚本，也不以伪造 CPU、在线时间或贡献数据制造“系统运行中”的错觉。

## 视觉和内容层级

- 深墨黑作为底色，正文为清楚的浅灰白；磷绿用于当前路径、主要操作和焦点，琥珀只标识少量次级信息。
- 默认配色为 `black`，另外提供 `amber`、`dracula`、`nord`。右上配色选择器与 `theme`／`theme black` 等命令控制同一个状态，保存于 `kernel-theme` Cookie，属性为 `Path=/`、`Max-Age=31536000`、`SameSite=Lax`，HTTPS 时加 `Secure`。head 在样式加载前读取同一 Cookie，避免恢复配色时闪烁。首次访问与无 JavaScript 时均保持默认黑色，不根据操作系统自动切换。四种配色均保持正文、链接和焦点可辨认。
- 会话栏、当前路径、提示符和列表元信息使用系统等宽字体；中文正文选择可读的系统字族，不依赖远程字体或前端构建链。
- 所有主要内容沿同一个终端输出区展开。分类、标签和归档以目录项、命令与真实链接呈现，不设置常驻资源管理器侧栏。
- 文稿是紧凑的文件行，编号、日期与标题形成清楚列关系。长标题可换行，无封面也保持完整布局，不用封面卡片或多行摘要块代替文件目录。
- 站点自述作为简短 README 输出，或通过 `cat README.md` 查看；不能重新长成独立大标题导语区或作者名片。
- 会话顶部只保留必要的身份与路径信息，不增加传统导航横栏、IDE 页签或多窗口仪表盘。
- 正文保持稳定阅读栏、足够行距、清楚的标题层级，支持宽代码、表格、图片、公式与引用。主题装饰不覆盖正文内容。
- 手机保留同一个连续会话，按可读空间重新排列文件日期与标题；提示符、可点击文件和返回目录入口都必须可用，不用横向滚动代替基本布局。

## 三条视觉审阅标准

1. **首屏只有一个主要输出区。** 在 1440px 与 390px 宽度下，除紧凑会话栏外，第一组主要内容就是路径、命令或文件列表。不得出现常驻左／右栏、顶部品牌导航加大导语区、作者卡片等第二套博客结构。
2. **文件目录是真正的连续行。** 编号、日期、文稿标题在整列中有一致对齐；相邻行依靠文字层级和轻分隔区分，不以独立卡片背景、圆角框、封面网格或长摘要重复占满首屏。长标题、无图与少量条目均应成立。
3. **阅读与退出发生在同一个会话中。** 打开文章后仍能识别当前文件与 `less` 语境，正文为单栏，`q`／返回目录和提示符易于找到。不能为了文章目录、作者资料或推荐阅读重新挤出第二栏；390px 下可点击与键盘操作均保留清楚入口。

## 数据与配置

列表使用 `data.rows`，详情使用 `log`，链接使用服务端已有 URL。导航、分类、标签、归档和友链由真实 `init` 数据产生；不能把当前分页的数量或条目伪装为全站总量。

`terminalUser` 默认 `user`，只作为显示文本。`introTitle` 是 README 输出中的小标题，留空时使用站点名称 `webs.title`，不再使用默认大口号；当前实例为“小春 ' s blog”。首页说明优先使用明确配置的 `introText`，然后是站点副标题 `webs.second_title`、站点描述 `webs.description`，最后是默认个人记录文案。

`profileText` 留空时不显示自述；`githubUrl` 仅接受 `https://` 地址，未配置或不合法时隐藏；`footerText` 留空使用默认短句。示例配置中的用户名 `xiaochun` 与 GitHub 链接来自目标站点公开信息，其他个人身份不作推断。

普通文本与属性必须正确转义；列表摘要按运行时语义呈现，详情只渲染正文，不重复摘要。处理空字符串时使用有内容判断，不能只判断字段是否存在。

## 交互边界

导航、搜索、分类和分页指向真实博客路由。主区提供直接的文稿选择和阅读键位；可点击、可提交的基本入口与正常焦点导航同时保留。桌面初始焦点落在主区，手机不自动聚焦输入框或弹出软键盘。弹层使用清楚焦点、Escape 关闭与焦点恢复。

终端输入支持 `help`、`ls`、`ls -lt ./posts/`、`cat 01`、`less 01`、`cat README.md`、`q`、`next`、`prev`、`tags`、`categories`、`archive`、`links`、`cd <分类名>`、`search Java`、`grep Java`、`cd ~` 和 `clear`。`ls` 与文章编号只覆盖当前分页；`search` 与 `grep` 提交服务端搜索；目录命令映射实际分类、标签、归档与友链路由。`q` 返回文章目录，前后导航需在无可用目标时给出边界提示。

命令输入框内的上下方向键浏览本次输入历史，`clear` 只清空本次会话输出，不更改文章或站点数据。没有 JavaScript 时，真实文章链接与搜索表单继续可用。可点击文件与可输入命令是同一组真实操作的两种入口。

`theme` 显示可用配色；`theme black`、`theme amber`、`theme dracula`、`theme nord` 切换当前浏览器的外观，不更改站点文章或服务端配置。选择器与命令结果应保持一致，存储不可用时本次页面仍能切换。

尊重 `prefers-reduced-motion`。不加入闪烁屏幕、持续打字动画、强制音效、假进度或模拟日志刷新。代码复制等功能需提供真实成功或失败反馈。

## 键盘状态与焦点

键盘行为已按以下状态独立复验，文稿选择无需逐个 Tab 遍历。

- **列表主区：** `↑`／`↓` 与 `k`／`j` 选择当前页真实文章，选择状态清楚且滚动到可见范围，`Enter` 使用文章原生链接。不能把分类链接或隐藏条目混入文章选择序列。桌面首次进入主区即可操作。
- **阅读主区：** `↑`／`↓` 与 `k`／`j` 滚动正文；Space／Shift+Space 和 PageDown／PageUp 前后翻屏；Home／End 到正文首尾；`q` 返回目录。页面内已有链接和控件保留原生操作。
- **进入与退出输入：** 主区 `/` 进入搜索，`:` 进入命令。Esc 取消当前输入并恢复文稿选择；没有可选文稿时回到主区。手机只在用户明确点选输入时弹出键盘。
- **命令编辑：** 候选关闭时 `↑`／`↓` 浏览输入历史；输入即显示候选，`↑↓` 选择，Tab 接受候选，Enter 接受已选候选，再按才执行；Shift+Tab 与空输入 Tab 保留正常焦点移动。Ctrl+U 清空输入，Ctrl+K 删除光标之后的内容。Ctrl+C 在无选区时取消输入，有选区时保留复制。
- **原生输入与浏览器：** 输入框、文本编辑区域和 IME 组合输入期间不响应全局单字键。Ctrl+A 保持全选；Ctrl/Cmd+L、R、T、W 等浏览器快捷键不被拦截。补全与历史不能截断中文组合输入。

## 兼容与验收

公共工具固定至 `fa397df332576b9dd798ac59a40d4ba96b3266a7`，基准为官方 ZrLog 3.9.2。该版本不存在的文章可能以 HTTP 200 返回空 `log`；主题显示明确的未找到内容，不自行改写路由。相邻文章字段需排除指向当前文章的占位对象。

数学公式沿用服务端输出的 HTML，主题打包 KaTeX 0.16.22 样式与 WOFF2 字体，不在浏览器重新渲染公式。来源及完整许可证见 [third-party.md](third-party.md)。避免以全局 SVG 宽高规则破坏公式内部图形。

单终端版本已有目录／ZIP 及桌面／手机验收记录，保存在 `runtime-acceptance.json` 与 `browser-acceptance.json`。已有验收覆盖首页、分页、分类、标签、归档、搜索、详情、聚合页、空态，以及命令与真实链接的对应关系；桌面和手机均检查长标题、特殊字符、无图、正文资源与横向溢出。本次文稿选择、阅读键位与命令编辑已通过独立浏览器验收，详见浏览器记录中的 `keyboard` 字段。真实评论提交和后台主题配置需在实际站点额外验证。验证结果与预览图应来自当前实现的实际渲染；完成前不标注新行为已通过或已发布。

### 服务端跳转后的会话恢复

通过当前标签页的 `sessionStorage` 保存选中文稿、列表路径、滚动位置、命令历史及未提交草稿。分页、目录等命令引起的服务端跳转后，桌面恢复提示符焦点；`open`、`cat`、`less` 打开文章时则聚焦阅读区，方向键与空格立即可用；已提交命令不重复填入。键盘打开文章后进入阅读区，`q` 返回原列表并恢复选中项。刷新恢复草稿与阅读位置，带锚点的链接保留原生定位。手机不自动聚焦输入框，存储不可用时仍保留正常服务端导航。状态仅用于本标签页交互，不提交到服务端。

桌面终端窗口最大宽度为 960px，居中显示；手机继续使用完整可用宽度。文章与文件列表共用这一宽度边界。

CSS 与 JS 地址带文件 SHA-256 前 12 位作为 `v` 参数，避免运行时一年 immutable 缓存让旧页面继续使用旧文件。资源修改时同步更新 `header.ftl` 的参数，并核对实际响应地址与渲染结果。

### 页面数据与补全

`terminal-data.ftl` 输出 `script#kernel-data[type="application/json"]`：`schemaVersion=1`，`articleScope=current-page`，`homeUrl`、`searchUrl` 以及 `articles/categories/tags/archives/links` 数组。条目具有 `title/url`，文章另有当前页 `index`。数据只来自官方 DTO 的公开字段，JSON 字符串转义并将 `<` 写为 Unicode 转义，避免提前结束 script 元素。不包含正文或后台数据。

命令与补全优先读取该数据，缺失时回退到原生链接。`cat`／`less` 可用编号、标题或文件名查找候选；`cd` 补全分类；`categories <名称>`、`tags <名称>`、`archive <名称>` 和 `links <名称>` 进入对应的真实 URL，无参数则列出目录。候选在命令框上方即时显示，`↑↓` 选择、Tab 接受默认或选中项、Enter 接受选中项而不立即执行；未选择候选时 Enter 执行原输入。Esc 先关闭候选，再按取消输入。选择命令后自动补参数空格；空输入 Tab 与 Shift+Tab 保留原生焦点移动。光标在文本中间或 IME 组合期间不补全。

选中文稿后输入 `open` 即可打开当前选中项，无需编号；没有选中项时提示先选择，不会随意打开第一篇。`open` 也支持命令名自动补全。

### 彩蛋维护约定

隐藏入口不列入帮助、补全、导航、README 命令表或历史记录。彩蛋采用本地 canvas 和原生 dialog，不访问外部资源、不播放声音。Esc 与可点击按钮退出后恢复原焦点，关闭时取消动画与事件监听。遵循减少动态效果偏好，后台标签页暂停动画。测试记录见 `browser-acceptance.json` 的 `easterEgg`。

`terminalHost` 控制提示符的主机显示名，默认 `blog`，与 `terminalUser` 一样只用于显示且经过 HTML 转义。页面不重复维护版本号，版本以 `template.properties` 为准。独立配置验收覆盖不同站点、用户名、主机显示名、个人链接与特殊字符转义。
